# Anniversary website — Vercel deployment

This is a static website. The main page is `index.html`; its photos and page content are embedded in the file.

## Deploy with Vercel
1. Sign in at https://vercel.com/ and choose **Add New → Project**.
2. Import a Git repository containing this folder, or deploy this folder using the Vercel CLI.
3. For a plain HTML site, leave the Framework Preset as **Other**.
4. Leave Build Command and Output Directory empty (or use `.` as the output directory if prompted).
5. Click **Deploy**.

No Netlify configuration or build step is required.
